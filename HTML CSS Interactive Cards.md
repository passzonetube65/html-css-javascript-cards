- ✅ Use `prefers-reduced-motion`
- ✅ Render from data, not copy-paste

## 🔧 Troubleshooting

| **Problem** | **Fix** |
|--------------|-----------|
| **Cards misaligned** | Check grid gap |
| **Hover janky** | Use `transform` |
| **Flip not working** | Add `perspective` |
| **Mobile overflow** | Use `minmax(0, 1fr)` |
| **Render fails** | Check JSON shape |
| **A11y issues** | Add ARIA roles |
